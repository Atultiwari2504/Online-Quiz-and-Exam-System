# 🧠 Online Quiz & Exam System

## 📌 Overview
A full-stack web application for conducting quizzes and exams with user authentication and real-time evaluation.

## 🎯 Features
- User registration & login
- Dynamic quiz system
- Score evaluation
- Database integration

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Flask (Python)
- Database: MySQL

## ⚙️ System Architecture
- Frontend → Backend (Flask API) → Database (MySQL)

## 🚀 How to Run
1. Clone repository  
2. Install dependencies  
3. Configure MySQL database  
4. Run Flask server  

## 📂 Project Structure
- `/` HTML files
- `/css` CSS
- `/js` JS
- `/app.py` – Backend logic
